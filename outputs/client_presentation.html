This provides 100% legal, certified county records with zero CAPTCHA interruptions.

Slide 04 / Database & History

HOW Does The Data Update?

Smart PostgreSQL deduplication and automated price change triggers

⚡ Zero Duplication (UPSERT)

Each property is uniquely indexed on (source, external_id). When a property is re-scraped, the database executes an ON CONFLICT DO UPDATE. Existing rows are updated in-place—your database never bloats with duplicate records.

📉 Automated Price Drop Auditing

An internal PostgreSQL trigger (trg_track_price_change) watches every record. When a seller lowers their price, the trigger instantly records the old price, new price, and timestamp in the price_history table.

📊 What This Means for Clients:

  • Track historical price cuts to spot motivated sellers before competitors.
  • Audit listing status transitions (Active → Pending → Sold).
  • Generate daily delta reports showing only new listings or price adjustments.
