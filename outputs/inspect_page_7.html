JOURNEY 01

Suburban Residential Home Search, Saved Alert & Tour Scheduling

Primary Actor: Elena Rodriguez (Homebuyer)

Covers the discovery, evaluation, dynamic cost modeling, search alert subscription, and physical tour booking flow for residential properties in Texas metropolitan areas.

1
Discovery & Location Query: Enters target metro, neighborhood, or zip code (e.g., "Frisco, TX") into omni-search bar. Toggles to "For Sale" view. Map renders interactive clusters and individual listing pins with asking prices.
2
Granular Filter Application: Filters for $450k–$650k, 4+ beds, 2.5+ baths, 2+ garage spaces, and minimum 0.25-acre lot size. Uses the interactive polygon tool to encircle a specific school attendance boundary.
3
Property Evaluation & Cost Modeling: Opens Property Detail Page. Reviews high-res gallery, CAD assessed tax value, and school ratings. Adjusts the Texas Payment Calculator to factor local 2.2% property tax rate and $125/mo MUD bond assessment.
4
Search Subscription & Favoriting: Clicks "Save Property" and writes private note ("Great backyard, need to check MUD taxes"). Saves the custom polygon search with "Instant Push & Email Alert" selected for new matching inventory.
5
Tour Scheduling Request: Selects "Request a Tour" button. Selects preferred date and time slot (Saturday at 10:00 AM). Inputs contact info and confirms pre-approval status. System validates phone via SMS code.
6
Confirmation & Agent Routing: System routes request to listing agent or participating premier partner. Sends calendar confirmation to buyer. System prompts user to review mandatory TREC Information About Brokerage Services (IABS) disclosure.
Expected Outcomes: Search saved, instant notification schedule active, tour inquiry logged in CRM, buyer receives email confirmation with agent contact details.
Failure & Edge States: Zero results in polygon (prompts filter expansion); agent unavailable for requested time (suggests alternate slots); SMS verification timeout (resend code prompt).
JOURNEY 02

Rural Parcel Lookup, GPS Field Boundary Walk & Acreage Analysis

Primary Actor: Caleb Sterling (Acreage Seeker) / Field Professional

Examines the cadastral parcel lookup, aerial boundary review, on-site mobile GPS walking, agricultural exemption check, and project export workflow across Texas rural counties.

1
Cadastral Search: Enters County Appraisal District Property ID (APN) or recorded owner surname into search bar (e.g., "Gillespie County, Parcel 14209"). Platform zooms map directly to parcel centroid with boundaries highlighted in gold.
2
Attribute & Ag Valuation Inspection: Inspects parcel slide-out card: confirms 48.65 surveyed acres, recorded deed reference, legal description, and current 1-d-1 Agricultural Exemption status (cattle grazing valuation vs. market value).
3
Layer Exploration: Toggles base map from street map to USGS High-Resolution Topographic layer to inspect elevation contours, seasonal creek beds, and potential flood draw areas. Toggles Railroad Commission (RRC) pipeline overlay.
4
On-Site Live GPS Walking: Arrives at physical property. Launches mobile app and taps "Locate Me". Live blue location dot with directional compass appears inside parcel boundary. Walks northern fence line to verify physical corners against digital boundary.
5
Measurement & Waypoint Drop: Uses interactive measurement tool to measure road frontage (1,320 feet) and drops a custom waypoint pin labeled "Potential Barn Site / Water Well Needed" with attached field photograph.
6
Project Save & Data Export: Saves parcel into custom folder "2026 Hill Country Ranch Candidates". Clicks "Export Data" to generate a standardized KML and CSV file containing boundary coordinates, APN, and CAD assessment data for offline use.
Expected Outcomes: Parcel boundary verified on-site, field pins and photos synced to cloud, agricultural tax risk noted, export file delivered for surveying team.
Failure & Edge States: Cellular dead zone (triggers offline cached map view); unmapped rural parcel geometry (displays CAD tax card with "Boundary geometry pending county update").
